# שחרור MyOto 2.0

## תצוגה מקדימה

מפעילים מקומית `npm ci`, ואז `npm run build` ו־`npm run preview`. התוצר נגיש ב־`http://localhost:4321/MyOto/`. לכל PR יש ארטיפקט `myoto-preview` ב־GitHub Actions. משרתים אותו מתחת לנתיב `/MyOto/` כדי שהקבצים והנתיבים הישירים ייטענו.

בבדיקת הקבלה פותחים קישור לוחית ישן, דוח לרכב פעיל, רכב ארכיוני ומספר צמ״ה, ודף שנתון ישיר. בודקים סטטוס, נסועה, ריקולים, שיתוף והורדת JSON/PNG, וכן PDF דרך חלון ההדפסה. מומלץ לשמור דוח דוגמה עבור כל סוג בדיקה מקומית. לוחיות הדוגמה הגולמיות נשארות מחוץ למאגר.

## מעבר

לאחר אישור מפורש לשחרור, שומרים את קומיט הייצור הנוכחי ואת קובץ הפריסה המאושר. מוודאים שכל PR עבר CI וביקורת, כולל תוצר Static Preview. משנים את מקור ההגשה בהגדרות Pages ל־GitHub Actions ואז מפעילים ידנית את Publish MyOto to GitHub Pages מענף main. רצוי להגביל את סביבת `github-pages` לענף ברירת המחדל. [הגדרת מקור פרסום](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Rollback

אם האתר הקודם פורסם מתיקיית השורש של main, מחזירים את אותה הגדרת מקור, כאשר קובצי הייצור הקודמים זמינים בשורש. אם הייצור כבר הוגש דרך Actions, משחזרים את תוצר ההפצה הקודם או מפרסמים מחדש את הקומיט הקודם לפי נוהל השחרור. בודקים שוב מהכתובת הציבורית, ממחשב ומטלפון, טעינת עמוד, קישור קיים וחיפוש רישוי.
